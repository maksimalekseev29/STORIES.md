# # User Stories — Трекер привычек
# US-01 — Создание привычки
Как пользователь, я хочу создавать новую привычку с названием и описанием,
чтобы начать отслеживать её выполнение.

Критерии приемки:
Можно указать название привычки.

Можно добавить описание привычки.

Созданная привычка появляется в списке активных.

# US-02 — Настройка периодичности привычки
Как пользователь, я хочу задавать периодичность привычки (ежедневно / по дням недели),
чтобы отмечать её в нужные дни.

Критерии приемки:
Можно выбрать режим «ежедневно».

Можно выбрать конкретные дни недели.

Настройка сохраняется для выбранной привычки.

# US-03 — Указание желаемого времени выполнения
Как пользователь, я хочу указывать желаемое время выполнения привычки,
чтобы получать напоминание в подходящий момент.

Критерии приемки:
Можно указать время выполнения.

Время сохраняется в настройках привычки.

Время учитывается при формировании напоминаний.

# US-04 — Архивирование и удаление привычки
Как пользователь, я хочу архивировать или удалять привычки,
чтобы убирать неактуальные из основного списка.

Критерии приемки:
Можно архивировать привычку.

Можно удалить привычку.

Архивированные привычки не отображаются среди активных.

# US-05 — Ежедневная отметка выполнения
Как пользователь, я хочу каждый день отмечать статус привычки (выполнено / пропущено),
чтобы фиксировать свой прогресс.

Критерии приемки:
Можно отметить привычку как выполненную.

Можно отметить привычку как пропущенную.

Отметка сохраняется в журнале за текущий день.

# US-06 — Заметка к отметке за день
Как пользователь, я хочу оставлять короткую заметку к отметке за день,
чтобы фиксировать контекст выполнения.

Критерии приемки:
Можно добавить текстовую заметку.

Заметка привязывается к конкретной отметке.

Заметка отображается в журнале и календаре.

# US-07 — Просмотр календаря отметок
Как пользователь, я хочу видеть календарь отметок по привычке,
чтобы оценивать регулярность выполнения.

Критерии приемки:
Отображается календарь за выбранный период.

Дни с выполненными отметками выделены.

Дни с пропусками также отображаются.

# US-08 — Подсчёт текущего стрика
Как пользователь, я хочу видеть текущий стрик (непрерывную цепочку дней),
чтобы поддерживать мотивацию.

Критерии приемки:
Система анализирует отметки за последние дни.

Текущий стрик рассчитывается автоматически.

Результат отображается для выбранной привычки.

# US-09 — Подсчёт лучшего стрика
Как пользователь, я хочу видеть лучший стрик как личный рекорд,
чтобы сравнивать текущие успехи с максимумом.

Критерии приемки:
Система анализирует всю историю отметок.

Определяется максимальная непрерывная цепочка дней.

Результат отображается пользователю.

# US-10 — Процент успешности за месяц
Как пользователь, я хочу видеть процент успешности внедрения привычки за месяц,
чтобы оценивать общий прогресс.

Критерии приемки:
Система учитывает выполненные и пропущенные отметки.

Рассчитывается процент успешности за месяц.

Результат отображается для выбранной привычки.

# US-11 — Список активных напоминаний на сегодня
Как пользователь, я хочу получать список активных напоминаний на сегодня,
чтобы не забывать о привычках.

Критерии приемки:
Формируется список привычек с напоминаниями на текущий день.

Учитывается периодичность и желаемое время.

Список отображается пользователю.

# US-12 — Сохранение и загрузка данных
Как пользователь, я хочу сохранять и загружать профиль привычек и историю отметок,
чтобы данные не терялись между запусками.
